# SIVEP API

Backend Laravel 13 (API REST) de SIVEP.

La guía completa de instalación, base de datos, usuarios demo y endpoints está
en el [`README.md`](../README.md) de la raíz del repositorio.

Comandos frecuentes:

```bash
php artisan migrate --seed
php artisan serve
php artisan test        # requiere la base sivep_test
./vendor/bin/pint
```
